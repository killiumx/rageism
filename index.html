Discord Webhooks
Auto-post announcements to Discord. Add as many webhooks as you like — one per channel, e.g. a #match-results channel, a separate #tdm channel, a #registrations channel, a #scrim-signups channel, and a private admin-activity channel. Each webhook only fires for the event type it's set to, so you can route match results, TDM results, team wins, player sign-ups, team registrations/approvals, scrim/tournament signup requests + acceptances, and announcements to whichever channels you want. Use "Who gets @mentioned" to control whether the whole roster (captain, manager & every member with Discord linked), just the captain, or nobody gets pinged for that channel — and optionally override the message text per webhook with tokens like {team}, {match}, {map}, {date}, {time}, {mode}, {mentions}.
Available tokens depend on the event: {mentions} {team} {match} {map} {date} {time} {mode} {player}

Stream Overlay (TikTok LIVE Studio / OBS)
Built for a vertical 9:16 canvas (recommended: 1080×1920). TikTok's mobile app can't layer browser overlays directly — you'll need TikTok LIVE Studio (free desktop app for gaming streams) or OBS routed to TikTok. In your scene: add this link as a Browser Source, sized to your full canvas, layered on top of your game capture. The live score sits at the top, a rotating Best/Recent/Weekly leaderboard sits at the bottom, and the middle stays clear for your gameplay or facecam.
Leaderboard Broadcast Overlay
A clean standings table sized for a widescreen 16:9 canvas — built for tournament broadcasts, TDM simulators, or PMGC-style standings graphics. Pick which board it should show, then add the link as a Browser Source in OBS. Scrims and TDM are always kept separate.
Custom Ranking Boards
Simple rank + name graphics like "Top 10 NA" — no wins/kills needed. Type names in order, one per line, then pick "Custom Ranking" as the Source above.
Sponsor / Shoutout Slides
One line each — every line becomes its own slide in the ticker rotation (both the mini overlay and any stream you're running). Good for "Sponsored by X," shoutouts to streamers you're bringing on, or a Discord invite plug.
